## Verification (run 2026-11-05)

The scored set (`evals/sentry_prs.json`) is generated by
`evals/build_pr_set.py` from the official `sentry.json`, not edited by hand.

1. Label check: `evals/check_labels.py` looks for identifiers named in each reference comment inside the PR's real diff. Result: PR 92393 scored 0 hits on all 4 comments (control, excluded). Each of the other 7 PRs has hits.
2. By-hand confirmation of the 4 comments with no identifier hits:
    - 67876, "OAuth state uses pipeline.signature": present in the diff (`state = pipeline.signature`, comparison with `pipeline.signature`).
    - 67876, "metadata[sender][login] without checking sender": present (`!= integration.metadata["sender"]["login"]`).
    - 93824, "break out of the loop at the deadline": the deadline loop is in the diff (`while process.is_alive() and (deadline is None or ...)`).
    - 80528, "returns the original monitor.config": present (a modified copy `config` is built, but `"config": monitor_environment.monitor.config` is used).

Limitations: this verifies that comments refer to code in the PR, not that each comment is a true bug. That is the dataset authors' judgment.
